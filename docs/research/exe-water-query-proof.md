## 6. Feature identity

`FeatureRef` uses a source/product namespace and exact retained revision. WFD GB510804505600
is an assessment-unit feature, not an inferred universal River Exe object or immutable physical
shoreline. A new detection cell/time does not replace it. No extra Meridian river identity, network,
centreline or connectivity is necessary for this proof.

PHI UID is an inventory-object identity. RFO rec_out_id identifies an outline/inventory object;
rec_grp_id is a separate event association, with original names/dates/causes retained. The feature
query links other evidence by **spatial intersection within WFD geometry AND the study**, explicitly
not cross-source entity equivalence. Claims keep their own geometry/time even when associated.

Claim IDs use source-native keys/components or month/parent-grid cell position; claim revisions
use exact retained product bytes. Definitions have separate revisions. A snapshot checksum,
physical/property question, source version and materialized artifact are distinct identities.

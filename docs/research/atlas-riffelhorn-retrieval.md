## 7. Query semantics

Transformed rectangles have 32 segments per edge, always_xy2D operations and the inherited coordinate qualification. Query applicability intersects the core; native source geometries remain intact.

Vectors use point `covers` including boundaries, or positive-area area intersection. Raster points use native affine half-open row/column membership: a DTM seam selects one tile, outer maximum-x/lower-y grid edges can have no cell. Height areas return intersecting support and conservative window descriptors, **not bulk values or a new aggregate**. WorldCover areas count native cell centres inside the transformed query polygon; candidate window edges are filtered exactly. Counts are sample classifications, not physical area fractions/confidence. Different representation predicates remain explicit.

Temporal predicates are inclusive calendar-year ranges or explicitly unknown, with separate `evidence-epoch` and `product-reference` roles. Source nominal/survey/release/distribution bases remain in every result. Unsupported exact-date/validity interpolation fails; unknown does not match every requested period. No-match means no matching retained evidence under these predicates, never physical absence.
